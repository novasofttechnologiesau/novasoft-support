# Contributing

Use fictional data, a dedicated test database and a local checkout. Follow README setup,
run `npm run build` and the backend tests in `docs/testing.md`, and include a regression test
for changes to access control. Run `cargo check --locked` in `apps/desktop/src-tauri` for
native changes. Explain the problem, behavior change and validation in your pull request.

Do not submit real device reports, private tickets, access tokens, `.env` files or uploaded
customer files. Use GitHub private vulnerability reporting for security issues.
Large changes should start with an issue to agree on scope. Support is best effort.
By contributing, you agree that your contributions are provided under this project's MIT license.
