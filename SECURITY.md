# Reporting a vulnerability

Use the repository's **Security → Report a vulnerability** option on GitHub. Include the
affected version, a minimal reproduction using fictional data, and the expected impact.
Do not disclose exploit details or private data in a public issue while a report is being assessed.

This is an initial developer preview. Reports are handled on a best-effort basis; no
response-time commitment or production security certification is offered.
Read [the security model](docs/security.md) for release limitations.
